# Non-Goals (Q1 Scope Boundary)

The following systems are deferred from Q1 scope. They are not promised, planned, or partially built — the project will only treat them as in-scope after explicit re-prioritization. The list exists to keep the early roadmap honest. For what *is* in scope, see [current_status.md](current_status.md) and [roadmap.md](roadmap.md).

## Client Features
- [ ] Game AI (players only)
- [ ] Save/load system
- [ ] Pause / time controls
- [ ] Mod support
- [ ] Multiplayer beyond single-client testing
- [ ] Replay system
- [ ] Tutorial or onboarding

## Server Features
- [ ] Multiple simultaneous players
- [ ] Session persistence across server restarts (state lost on reboot is OK)
- [ ] Complex event log UI
- [ ] Analytics dashboards
- [ ] Server auto-scaling or Kubernetes

## Content
- [ ] Full map with multiple countries
- [ ] Production chains beyond basic goods
- [ ] Warfare, military units, diplomacy
- [ ] Technology trees or research
- [ ] Population migration
- [ ] Trade routes
- [ ] Buildings or improvements
